# Viralyst topic bank (evergreen, Zack/Jaguaqo recipe)

Rules: hook first, payoff last, 30-45 s, two-sided question at the end, a pinned first comment
with a bonus fact + "Look it up". Every fact verified against 2+ sources before the storyboard.
Say "theory"/"debated" where science is not settled. No instructions for anything dangerous.
Rotate pillars so two videos in a row never share one. Status: todo / done (date).

Already made: yawning (3D, shelved), pirate eye patches, mantis shrimp, Hiroo Onoda,
wrinkly fingers, Roman concrete.
